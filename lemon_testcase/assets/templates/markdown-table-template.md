# Markdown 表格模板

## 字段

| canonical key | 显示名称 | 必填 | 说明 |
|---|---|---|---|
| case_id | 用例编号 | 是 | 文档内唯一编号 |
| name | 用例标题 | 是 | 单一可验证目标 |
| area | 所属模块 | 是 | 模块、页面或 API 资源 |
| flow_type | 流程类型 | 是 | 正常流程/异常流程 |
| test_method | 测试方法 | 是 | 正常流程/非法输入/边界值/状态与恢复等 |
| priority | 优先级 | 是 | P0/P1/P2/P3 |
| preconditions | 前置条件 | 是 | 执行前准备 |
| actions | 测试步骤 | 是 | 有序动作 |
| data | 测试数据 | 是 | 输入值、请求体、边界值或运行时变量 |
| assertions | 预期结果 | 是 | 可观察断言 |
| actual_result | 实际结果 | 否 | 执行后的实际表现 |

## 输出约定

数组字段使用 `<br>` 分隔；单元格内的竖线使用 `\|` 转义。第一行必须是表头，第二行必须是分隔行。表格应能被 `lemon_cases.py` 再次导入。

## 示例

|---|---|---|---|---|---|---|---|
