# 登录页 UI 演示说明

## 页面素材

- 截图：`login-page.png`
- 页面尺寸：1440 × 900 演示桌面宽度
- 数据：全部为虚构测试数据

## 可见组件

- 页面标题和产品标识
- 邮箱输入框
- 密码输入框
- 记住我复选框
- 登录按钮
- 忘记密码链接
- 错误提示区域

## UI 验证重点

1. 默认状态下登录按钮和字段标签清晰可见。
2. 邮箱和密码输入框有可访问名称。
3. 密码默认掩码，错误状态不展示明文密码。
4. 登录提交中按钮不可重复点击。
5. 错误提示位于相关字段附近并保持布局稳定。
6. 视口缩小时页面不出现横向溢出。
7. 键盘可以按邮箱、密码、记住我、登录、忘记密码顺序操作。

## OCR/视觉测试说明

如果使用图片适配器，图片只证明可见布局和文字；验证码出现条件、网络超时和账号锁定需要结合 PRD/API 生成，不应从截图臆测。
