# Lemon Portal 登录功能 PRD（演示数据）

## 1. 背景

Lemon Portal 为用户提供邮箱密码登录能力。登录成功后进入工作台；失败时保留邮箱输入并展示明确提示。本文档仅用于测试 `lemon_testcase` 的功能生成，不代表真实产品。

## 2. 角色与入口

- 未登录用户可以打开登录页。
- 注册用户可以使用已验证邮箱和密码登录。
- 被锁定用户不能继续尝试登录。
- 已登录用户访问登录页时应跳转工作台或显示已登录状态。

## 3. 字段规则

| 字段 | 规则 |
|---|---|
| 邮箱 | 必填；合法邮箱格式；长度 6-128 个字符 |
| 密码 | 必填；长度 8-64 个字符；大小写敏感 |
| 记住我 | 可选；默认关闭；开启后延长会话有效期 |
| 验证码 | 连续失败达到 3 次后显示；5 分钟内有效 |

## 4. 主流程

1. 用户打开登录页。
2. 输入邮箱和密码。
3. 可选勾选“记住我”。
4. 点击“登录”。
5. 系统验证账号、密码、账号状态和验证码。
6. 验证成功后创建会话并跳转工作台。

## 5. 异常规则

- 邮箱为空：提示“请输入邮箱”。
- 邮箱格式错误：提示“请输入有效邮箱”。
- 密码为空：提示“请输入密码”。
- 密码错误：提示“邮箱或密码错误”，不泄露账号是否存在。
- 连续 3 次失败：展示验证码区域。
- 验证码错误或过期：提示验证码错误并允许重新获取。
- 账号锁定：禁止登录并展示解锁提示。
- 网络超时：保留已填写内容并允许重试。
- 登录按钮提交中：禁止重复点击。

## 6. 验收标准

- 正确凭证可以登录并进入工作台。
- 错误凭证不会泄露账号存在性。
- 必填和格式校验在提交前生效。
- 登录请求失败时不会创建错误会话。
- “记住我”影响会话有效期，但不改变认证结果。
- 连续失败、验证码、锁定和恢复流程可被验证。
- 密码输入默认掩码，页面和日志不展示明文密码。

## 7. 非功能要求

- 登录接口的目标响应时间由项目另行确认，测试数据不能自行假设具体 SLA。
- 登录页支持桌面和移动宽度。
- 键盘用户可以完成输入、提交和错误恢复。
